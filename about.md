# Editor Collab

Build Geometry Dash levels **together, live**.

- Hit the **Collab** button at the top of the editor
- **Host** a room and send your friend the 6-letter code
- They **Join** with the code and get your level instantly
- Everything anyone places, moves, edits or deletes shows up for everyone else
- See where your collaborators are looking with name markers

Everyone needs to point the **Server URL** setting at the same Editor Collab server.
